# Contribuindo

- Crie uma branch a partir de `main`.
- Use commits semânticos (`feat`, `fix`, `test`, `docs`, `refactor`, `ci`, `chore`).
- Antes do PR execute `npm ci`, `npm run typecheck`, `npm run lint` e `npm run build`.
- Nunca exponha segredos em variáveis `VITE_*`.
- Mantenha `presentation`, `domain` e `data` desacoplados.
- Explique no PR o comportamento alterado e como validá-lo.
